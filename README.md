# CampusConnect — Expanded Quick Demo

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Enter student details and use the sidebar.

No Firebase, API key, npm install, or backend setup is required.

## Features
- Student demo login and editable profile
- Dashboard with attendance, assignment and event summaries
- Attendance percentage and demo mark-present action
- Add/remove timetable entries
- Add assignments, mark submitted, undo submission and delete
- Add/remove announcements
- Add/remove campus events
- Create and delete personal study notes
- Dark/light theme toggle
- Responsive layout for mobile and desktop
- Browser localStorage persistence

## Data and real-time note
This is a front-end demonstration. Data is saved in the current browser using localStorage. It can notify other tabs of changes in the same browser, but it is not a shared online database and does not provide secure multi-user accounts. For genuine multi-device real-time use, connect Firebase or another backend.
